Google Refresh Token Generator

This is a one-time utility helper. To allow your Vercel server to connect to Google Drive silently in the background, we need to generate a permanent **Refresh Token** (Key) using OAuth.

Security note: This tool runs 100% locally in your browser. Your client secret is never sent to any third-party server except Google's official OAuth server. You can safely delete this file from your Desktop once you copy the token.
