### 3. 🗑️ 3-Tier File & Folder Deletion Cascade
* Implemented a bulletproof 3-tier deletion hierarchy in `app.js`:
  1. **Tier 1 (Safe Trashing)**: Sends `PATCH https://www.googleapis.com/drive/v3/files/{id}` with `{ trashed: true }`.
  2. **Tier 2 (Direct Deletion)**: If trashing is restricted, falls back to `DELETE https://www.googleapis.com/drive/v3/files/{id}`.
  3. **Tier 3 (Folder Unlinking)**: If permission fails, safely disassociates parent via `removeParents={folderId}`.

### 4. 🔑 OAuth Setup Helper & Sanitizer
* Updated `setup.html` with `prompt: 'consent'` to force Google to always issue a permanent, long-lived Refresh Token.
* Added 1-click token copy and automatic environment variable sanitization (`.trim().replace(/^["']|["']$/g, '')`) in `api/auth.js` and `api/share.js` to prevent syntax/newline corruptions.

### 5. 👻 Ghost Vault / Decoy Mode (Double Agent System)

* **Unified Drive Config**: Master and Decoy passwords and sharing configurations are safely unified in `.locker_config.json` on Google Drive.
