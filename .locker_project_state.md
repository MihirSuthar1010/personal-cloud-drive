### 2. 🛡️ Universal Bulletproof Upload & Download Engine (Zero-Error Guarantee)
* **Universal Format Support**: Any format in the world (`.7z`, `.zip`, `.bat`, `.cmd`, `.ps1`, `.exe`, `.msi`, `.dll`, `.tar`, `.iso`, media, raw binaries) uploads and downloads with zero errors.
* **MIME Sanitization**: For sensitive scripts or executables (`.bat`, `.cmd`, `.exe`, `.7z`), automatically enforces `application/octet-stream` on resumable upload initiation so Google Drive's API never blocks metadata.
* **Malware & Virus Scan Bypass**: Embedded `&acknowledgeAbuse=true&supportsAllDrives=true` across all download routes (in-memory XHR, direct stream, folder zip builder, and public share links).
* **RAM Optimization for Large Files**: Files > 80 MB bypass browser JavaScript RAM heap buffering (`ArrayBuffer`), streaming directly to Chrome's native download manager with zero memory exhaustion or tab freeze.
* **Multi-Tier Download Cascade**:
  * **Tier 1 (In-Memory Stream)**: Smooth real-time progress for standard files (< 80 MB) with live byte counters.
  * **Tier 2 (Direct Authenticated API Stream)**: `https://www.googleapis.com/drive/v3/files/{id}?alt=media&acknowledgeAbuse=true&supportsAllDrives=true&access_token={token}` directly triggers native browser multi-threaded download.
  * **Tier 3 (Official Google Export)**: Fallback to official Google `webContentLink` or `drive.google.com/uc?id={fileId}&export=download&confirm=t`.
* **Silent Token Auto-Renewal (Long-term Persistence)**:
  * Even if a download or upload is initiated after hours, 10 days, or 1 year, the engine verifies token age and auto-refreshes silently via `api/auth.js` using the permanent `GD_REFRESH_TOKEN`.
  * Automatic HTTP 401 retry: If a token expires mid-flight, it immediately re-mints a fresh token and retries without throwing error toasts.
